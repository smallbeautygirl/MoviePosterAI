論文題目（中文）

基於大型語言模型之電影海報自動生成與多維品質評估閉環框架

論文題目（英文）

A Closed-Loop Framework for Automatic Movie Poster Generation and Multi-Dimensional Quality Evaluation via Large Language Models

研究動機（給教授看的一段話）

電影海報是重要的視覺行銷媒介，然而現有的自動圖像生成方法缺乏針對海報領域的專屬評估指標，導致生成結果難以量化與優化。本研究提出兩個核心貢獻：(1) 建立一套涵蓋類型一致性、視覺吸引力與語意對齊的多維評估框架，並驗證其與人類評分的相關性；(2) 設計以 LLM 為核心的閉環生成系統，透過評估分數自動回饋優化提示詞，無需人工介入即可迭代提升海報品質。

兩個核心貢獻
貢獻一：評估框架
  • 類型一致性（CLIP Score）
  • 視覺吸引力（NIMA 美學模型）
  • 語意對齊（海報 vs 劇情摘要）
  • 與人類評分做相關性驗證
貢獻二：閉環生成
  • LLM 分析電影 metadata → 生成提示詞
  • Stable Diffusion 生成海報
  • 評估框架打分
  • LLM 根據分數修改提示詞 → 迭代
