你的論文「新貢獻」是什麼？

碩士論文必須有一個別人沒做過（或做得不夠好）的點 — 以下是幾個可行方向

A

🔄 自動迭代優化（Feedback Loop）

LLM 生成提示詞 → 生成圖像 → CLIP 評分 → LLM 根據分數修改提示詞 → 再生成，形成閉環自動優化

貢獻點：提出一個不需人工介入、可自動提升海報品質的迭代框架

✅ 新穎性高 ✅ CV 教授會有興趣 ⚠️ 實驗設計較複雜
B

📐 提出新的海報評估指標

現有指標（FID、CLIP Score）不是針對電影海報設計的。提出「類型一致性、角色顯著度、商業吸引力」等海報專屬指標，並驗證與人類評分的相關性

貢獻點：建立電影海報評估的 Benchmark，讓未來研究有標準可循

✅ 學術貢獻明確 ⚠️ 需要收集人類標注資料
C

🔬 LLM 提示詞策略的系統性比較

比較不同 LLM 提示詞設計策略（zero-shot、few-shot、chain-of-thought）對生成海報品質的影響，找出最有效的方法

貢獻點：為「如何用 LLM 生成高品質圖像提示詞」提供系統性的實驗依據

✅ 實驗設計清楚好執行 ✅ 3 個月內最可控 ⚠️ 新穎性相對較低
D

✨ A ＋ B 組合（推薦）

同時提出新評估指標（B）＋ 用這個指標驅動閉環優化（A）。評估框架是貢獻一，迭代生成是貢獻二

貢獻點：「提出指標 → 用指標優化生成」形成完整論文敘事，兩個貢獻相互支撐

✅ 論文結構完整 ✅ 最高學術價值 ⚠️ 工作量最大，需控制範圍
